# Details:

2. Ensure proper validation of feedback data
3. Maintain connection to AI adaptation workflow

Example implementation:
```typescript
// src/api/rest/routes/training.ts (continued)
import { FeedbackSchema } from '@fitnessai/types';

// Inside trainingRoutes function
fastify.post('/feedback', {
  schema: {
    body: FeedbackSchema
  },
  preHandler: [authenticate],
  handler: async (request, reply) => {
    const userId = request.user.id;
    const { sessionId, feedback } = request.body;
    
    try {
      const result = await trainingService.submitFeedback(userId, sessionId, feedback);
      return reply.send(result);
    } catch (error) {
      if (error.message === 'Session not found') {
        return reply.status(404).send({
          error: 'NotFound',
          message: 'Training session not found'
        });
      }
      throw error;
    }
  }
});
```
